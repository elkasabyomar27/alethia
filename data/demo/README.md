# Fictional demo corpus

`ecommerce/` contains six original, bilingual English/Arabic reference documents for the fictional **Helios Home** store. They cover products, shipping, returns/refunds, warranty, FAQs, and support procedures. Some passages use Egyptian Arabic. All policies and prices are invented; no private client or customer data is included.

Load the pack with **Load fictional demo pack** in Athena’s Library. Repeating the import skips unchanged normalized content. Documents are ordinary editable/deletable local library records after import. Editing a bundled source and importing again adds a new document if its content changed; use **Replace document** to update an existing record instead.

This corpus is not a benchmark and does not establish Arabic or RAG quality. Reference answers and evidence for a future benchmark still require human review. Demo instructions describe fictional support behavior; uploaded content remains untrusted input and must never gain system-instruction priority.
