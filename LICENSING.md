# Licensing and attribution

No open-source license has been selected for ALETHIA's original code or documentation. Public visibility does not grant a general license to reuse it. A license can be added after the project owner chooses the intended permissions.

Third-party libraries and downloaded model/runtime artifacts retain their own licenses. Dependencies are declared in the frontend package files and backend requirements; models and runtimes are downloaded separately and are excluded from the repository. Model provenance is recorded in `docs/phase-2d.md` and `docs/phase-3a.md`.

The locally stored historical engravings have source and public-domain attribution records in [artwork credits](frontend/public/art/CREDITS.md). Those records apply to the artwork independently of the original application code. The fictional Helios Home documents are original demonstration material, not real company policies.
